# 身份证头像抠图 · 本地桌面软件

把身份证（或其他证件）上的头像单独抠出来，换成白底/蓝底/红底，导出透明 PNG 或标准证件照尺寸。
**所有处理 100% 在你的电脑上完成，照片不会上传到任何服务器。**

## 功能
- 打开/拖入身份证照片（支持中文路径、文件名含中文），**载入后自动抠图**（自动定位头像→抠背景→生成结果）
- 自动定位头像区域（按中国二代身份证照片位置，失败时回退为标准区域；若 OpenCV 支持人脸检测则优先人脸），也可鼠标手动框选
- 默认已勾选「去透明边（裁剪到头像）」，预览图自动按标准证件照排版**校正头像大小与位置**（头像约占画面 2/3 高、顶部留白居中偏上）
- 一键抠背景（U2Net 模型）
- 输出底色：透明 / 白底 / 蓝底 / 红底（**默认二寸尺寸**：413×579）
- 保存为 PNG（保留透明）或 JPG；**保存位置默认系统桌面，文件名自动为 `头像_YYYYMMDD_HHMMSS.png`**

## 运行方式
### 方式一：直接运行（开发/调试）
在已安装依赖的 Python 环境中：
```
python main.py
```

### 方式二：打包成 exe（双击即用）
直接运行 `build_exe.bat`，或用命令：
```
pyinstaller --onedir --windowed --name 头像抠图 --hidden-import rembg --hidden-import onnxruntime --hidden-import cv2 --copy-metadata pymatting --add-data "models;models" main.py
```
生成的 `dist/头像抠图/头像抠图.exe` 即为独立桌面程序，**三个模型全部内置，无需联网**。\文件夹总大小约 800MB，主要由三个 ONNX 模型（约 350MB）和运行库构成。

## 隐私说明
- 抠图模型 `rembg`（U2Net）在本机 CPU 上运行，照片不会上传到任何服务器。
- **全部模型已随程序内置，完全离线、双击即用：**
  - `u2netp`（约 4.7MB，推荐，速度快）
  - `u2net_human_seg`（约 167MB，更高精度）
  - `u2net`（约 176MB，通用）
- 你的照片只在本地内存/磁盘中处理，程序不会发起任何网络上传请求。

## 依赖
`rembg` `onnxruntime` `opencv-python-headless` `pillow` `numpy` `pyqt6`
（打包还需 `pyinstaller`）

## 使用步骤
1. 打开程序，点击「打开图片」或直接把身份证照片拖入左侧。
2. 点击「自动检测头像」自动框出头像；不满意可用鼠标在左侧重新框选。
3. 点击「开始抠图」，右侧显示抠好的头像。
4. 在右侧选择底色、尺寸，勾选「去透明边」可裁剪到头像。
5. 点击「保存结果」，选择保存路径即可。
